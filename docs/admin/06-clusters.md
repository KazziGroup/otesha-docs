## Who can do this

Anybody with access to the console.

## Before you start

Nothing. It is the second tab on the Rota page.

## Steps

**1. Open Rota and switch to Clusters.**

![The rota in the admin console, by cluster, with a cluster heading and a start date marked. Marked on the screenshot: One cluster, and how many trees are in it. When each caretaker took this cluster on.](/img/admin-clusters-01-en.png "Rota · Clusters. The same rota, grouped by block instead of by person.")

Each card is one cluster — *Block A, Cluster 1 · 292 trees* — with everybody
tending it and the date each of them started.

**2. Use it to find gaps rather than people.**

By caretaker you can see who has nothing to do. By cluster you can see the
opposite: a block with nobody on it, or one carrying far more people than its
neighbours.

## How you know it worked

Nothing to confirm; this is a view. The count beside the tab is how many
clusters this zone has.

## If it goes wrong

> **Note:** The same person appears on several clusters, and the same cluster
> lists several people. Both are normal. The *since* date is what tells you how
> settled an arrangement is.
